### About Me

I'm a frontend engineer who enjoys turning complex requirements into clean, maintainable UI. I care about code quality, type safety, and building things that hold up in production — not just in a demo.

- 🔭 Currently building **Mortgage-calculator-FE**, a React + TypeScript + Vite project with proper tooling (Husky hooks, lint/format automation)
- 🧠 Deepening my fundamentals across JavaScript, TypeScript, React internals, testing, and performance — deliberately, not just by shipping fast
- 🛠️ Comfortable with React, TypeScript, state management, forms/validation (React Hook Form + Zod), and testing (Vitest, React Testing Library)
